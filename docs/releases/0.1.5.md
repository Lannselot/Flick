# Flick 0.1.5

Flick 0.1.5 introduces a content-first desktop interface and makes image
viewing more predictable across window, fullscreen, and browsing workflows.

- Adds distinct empty, loading, image, and error presentation states with
  transient status and first-use feedback.
- Keeps automatically fitted images responsive when the window or viewport is
  resized, while preserving explicit user zoom.
- Adds consistent File and context menus, including a shared `Quit` command,
  and hides application chrome in fullscreen mode.
- Restores the pre-fullscreen window geometry on exit and prevents fullscreen
  state from leaking into the next application launch.
- Adds transactional settings and live image-information dialogs.
- Strengthens asynchronous decoding, browsing-sequence reconciliation,
  decoded-image caching, and adjacent-image prefetching.
- Expands cross-platform process, architecture, UX, packaging, and performance
  coverage, including deterministic waits for observable UI state.
- Refreshes the verified SHA-256 pins for upstream `linuxdeploy` build 368 and
  Qt deployment plugin build 256 used by the Linux release workflow.

The supported platform baseline remains Linux and macOS 13 or newer.
