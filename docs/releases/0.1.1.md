# Flick 0.1.1

Flick 0.1.1 adds supported macOS 13+ distribution alongside Linux.

- Universal `arm64` and `x86_64` `Flick.app` bundle with deployed Qt frameworks
  and image plugins.
- Finder file associations, Open With/file-open events, reveal in Finder, and
  native Open, Settings, About, and Quit menus.
- Active-display ICC discovery through AppKit with color refresh on screen
  changes.
- macOS CI covering universal build, deterministic tests, installed bundle
  structure, signatures, plugins, and supported-format startup.
- Protected Developer ID signing, notarization, stapling, Gatekeeper,
  checksums, and provenance workflow for tagged releases.

The maintainer completed the native macOS workflow and real-device matrix for
this release candidate on 2026-08-13.
