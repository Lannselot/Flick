# Flick 0.1.2

Flick 0.1.2 is a release-pipeline correction following the withdrawn 0.1.1
publication attempt.

- Updates the pinned `linuxdeploy` SHA-256 to the digest published by the
  upstream GitHub release and independently verified against build 367,
  commit `07333c6`, dated 2026-08-01.
- Keeps the unchanged Qt deployment plugin checksum pinned.
- Adds an explicit macOS credential preflight so missing Developer ID or App
  Store Connect configuration fails with the exact missing secret name before
  keychain setup.

The application behavior and supported platform matrix are unchanged from the
0.1.1 release candidate.
